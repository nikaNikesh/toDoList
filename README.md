# Task Manager 
This is a minimalistic task manager for managing and controlling tasks.

### What can a task manager do?

- create and delete tasks
- assign a task priority
- filter by active and completed tasks
- search by task content

## Technologies used:

- ES6+
- JSX
- Bootstrap
- React component state
- Class components

## How to run?
1. Make sure you have [Node.js](https://nodejs.org/) installed.
2. Clone the repository.
3. Run 
### `npm start`
4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.


*This project was bootstrapped with Create React App.

*The application styles are created using the Bootstrap:  https://getbootstrap.com/.
